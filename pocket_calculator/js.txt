## 2. JavaScript de la zero

Creează un fișier `script.js`.

### Pasul 1: Selectăm elementele

```javascript
const input = document.querySelector(".input-container");

const plusButton = document.querySelector("#plus");
const minusButton = document.querySelector("#minus");
const multiplyButton = document.querySelector("#multiply");
const divideButton = document.querySelector("#devide");
const equalsButton = document.querySelector("#equals");
const resetButton = document.querySelector("#reset");
```

Acum avem acces la toate butoanele.

---

### Pasul 2: Creăm variabilele calculatorului

```javascript
let firstNumber = null;
let selectedOperator = null;
```

* `firstNumber` → primul număr introdus.
* `selectedOperator` → operația selectată (`+`, `-`, `*`, `/`).

---

### Pasul 3: Funcția pentru selectarea operației

```javascript
function selectOperator(operator) {
    firstNumber = Number(input.value);
    selectedOperator = operator;

    input.value = "";
}
```

Când apeși `+`, de exemplu:

1. Salvăm primul număr.
2. Salvăm operatorul.
3. Golim inputul pentru al doilea număr.

---

### Pasul 4: Adăugăm evenimentele pentru operatori

```javascript
plusButton.addEventListener("click", () => {
    selectOperator("+");
});

minusButton.addEventListener("click", () => {
    selectOperator("-");
});

multiplyButton.addEventListener("click", () => {
    selectOperator("*");
});

divideButton.addEventListener("click", () => {
    selectOperator("/");
});
```

Acum toate cele patru operații sunt conectate.

---

### Pasul 5: Funcția pentru calcul

```javascript
function calculate() {
    const secondNumber = Number(input.value);

    if (firstNumber === null || selectedOperator === null) {
        return;
    }

    let result;

    switch (selectedOperator) {
        case "+":
            result = firstNumber + secondNumber;
            break;

        case "-":
            result = firstNumber - secondNumber;
            break;

        case "*":
            result = firstNumber * secondNumber;
            break;

        case "/":
            if (secondNumber === 0) {
                input.value = "Error";
                return;
            }

            result = firstNumber / secondNumber;
            break;

        default:
            return;
    }

    input.value = String(result);

    firstNumber = null;
    selectedOperator = null;
}
```

---

### Pasul 6: Butonul egal

```javascript
equalsButton.addEventListener("click", calculate);
```

---

### Pasul 7: Butonul reset (C)

```javascript
resetButton.addEventListener("click", () => {
    input.value = "";

    firstNumber = null;
    selectedOperator = null;
});
```

# 3. Codul complet `script.js`

Poți copia tot codul de mai jos:

```javascript
const input = document.querySelector(".input-container");

const plusButton = document.querySelector("#plus");
const minusButton = document.querySelector("#minus");
const multiplyButton = document.querySelector("#multiply");
const divideButton = document.querySelector("#devide");
const equalsButton = document.querySelector("#equals");
const resetButton = document.querySelector("#reset");

let firstNumber = null;
let selectedOperator = null;

// Selectare operator
function selectOperator(operator) {
    if (input.value.trim() === "") {
        return;
    }

    firstNumber = Number(input.value);
    selectedOperator = operator;

    input.value = "";
}

// Operații
plusButton.addEventListener("click", () => {
    selectOperator("+");
});

minusButton.addEventListener("click", () => {
    selectOperator("-");
});

multiplyButton.addEventListener("click", () => {
    selectOperator("*");
});

divideButton.addEventListener("click", () => {
    selectOperator("/");
});

// Calcul
function calculate() {
    if (firstNumber === null || selectedOperator === null) {
        return;
    }

    const secondNumber = Number(input.value);

    let result;

    switch (selectedOperator) {
        case "+":
            result = firstNumber + secondNumber;
            break;

        case "-":
            result = firstNumber - secondNumber;
            break;

        case "*":
            result = firstNumber * secondNumber;
            break;

        case "/":
            if (secondNumber === 0) {
                input.value = "Error";
                return;
            }

            result = firstNumber / secondNumber;
            break;

        default:
            return;
    }

    input.value = String(result);

    firstNumber = null;
    selectedOperator = null;
}

// Egal
equalsButton.addEventListener("click", calculate);

// Reset
resetButton.addEventListener("click", () => {
    input.value = "";

    firstNumber = null;
    selectedOperator = null;
});
```

## 5. Test automat pentru butoane

Înainte să verificăm rezultatele matematice, putem verifica dacă toate butoanele există și au evenimente conectate.

Adaugă temporar la finalul fișierului:

```javascript
const buttons = [
    plusButton,
    minusButton,
    multiplyButton,
    divideButton,
    equalsButton,
    resetButton
];

buttons.forEach((button) => {
    if (button) {
        console.log(`✅ Buton funcțional: ${button.id}`);
    } else {
        console.error("❌ Buton lipsă");
    }
});
```

**Important:** Acest test verifică existența butoanelor, nu și corectitudinea operațiilor.
